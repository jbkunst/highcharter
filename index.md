# highcharter

Highcharter brings Highcharts to R. Turn data frames, time series and
statistical results into interactive visualizations, explore geographic
data and create financial charts with a flexible R interface.

## Installation

Install from CRAN:

``` r

install.packages("highcharter")
```

Or install the development version from GitHub:

``` r

remotes::install_github("jbkunst/highcharter")
```

## What’s included

One Highcharts bundle brings together Charts, Stock, Maps and Gantt.
Choose from dozens of chart types and combine them with tooltips, zoom,
drilldown, annotations, exporting and accessibility features.

- Chart R objects with
  [`hchart()`](https://jkunst.com/highcharter/reference/hchart.md): data
  frames, vectors, time series, forecasts and survival models all have a
  starting point.
- Create choropleths with
  [`hcmap()`](https://jkunst.com/highcharter/reference/hcmap.md) and
  bring your own geographic data.
- Explore financial time series and candlesticks with
  [`highchartstock()`](https://jkunst.com/highcharter/reference/highchartstock.md),
  technical indicators and Stock Tools.
- Make charts your own with themes, colors, labels and languages.
- Add interactive charts to Shiny applications and R Markdown documents.
