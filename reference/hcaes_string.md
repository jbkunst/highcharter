# Map point options using strings

Use this form when the column names come from variables, such as Shiny
inputs. Strings may also contain a single R expression.

## Usage

``` r
hcaes_string(x, y, ...)
```

## Arguments

- x, y, ...:

  Column names or expressions as strings. Only `x` and `y` can be
  supplied by position.

## See also

[`hcaes()`](https://jkunst.com/highcharter/reference/hcaes.md)
