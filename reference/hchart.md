# Create a highchart object from a particular data type

`hchart` uses `highchart` to draw a particular plot for an object of a
particular class in a single command. This defines the S3 generic that
other classes and packages can extend.

## Usage

``` r
hchart(object, ...)

# S3 method for class 'decomposed.ts'
hchart(object, ...)

# S3 method for class 'prcomp'
hchart(object, ..., choices = 1:2, scale = 1, loadings = FALSE, label = FALSE)

# S3 method for class 'princomp'
hchart(object, ..., choices = 1:2, scale = 1, loadings = FALSE, label = FALSE)
```

## Arguments

- object:

  A R object.

- ...:

  Additional arguments for the data series
  (<https://api.highcharts.com/highcharts/series>).

- choices:

  Two component numbers to plot on the x and y axes.

- scale:

  PCA score scaling exponent between 0 and 1. Zero plots raw scores.

- loadings:

  Draw and name the variable loading vectors on the PCA plot.

- label:

  Display observation names on PCA points.

## Details

Run `methods(hchart)` to see what objects are supported. Numeric
matrices use a heatmap by default. Set `type = "tilemap"` for hexagonal
tiles or `type = "contour"` for contour lines. Empirical distributions
from [`stats::ecdf()`](https://rdrr.io/r/stats/ecdf.html) use a step
line. One-way tables use columns in category order. Two-way tables use
the matrix heatmap. Use
[`margin.table()`](https://rdrr.io/r/base/marginSums.html) to choose
dimensions of a larger table.

For a GeoJSON FeatureCollection from geojsonio, each geometry family
gets its own layer. Supply `type` to select one layer explicitly.

## See also

[`hchart.constparty()`](https://jkunst.com/highcharter/reference/hchart.constparty.md)
for classification and regression trees.
