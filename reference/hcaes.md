# Map data-frame columns to Highcharts point options

Expressions are evaluated in the data frame and can use variables from
the function that created the mapping. `group` creates one series per
distinct value. Other named mappings become point options.

## Usage

``` r
hcaes(x, y, ...)
```

## Arguments

- x, y, ...:

  Columns or expressions to map. Only `x` and `y` can be supplied by
  position. A quoted column name or expression is also accepted.

## See also

[`hcaes_string()`](https://jkunst.com/highcharter/reference/hcaes_string.md),
[`mutate_mapping()`](https://jkunst.com/highcharter/reference/mutate_mapping.md)
