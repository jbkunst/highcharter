# Add a bundled community plugin to a chart

Add a bundled community plugin to a chart

## Usage

``` r
hc_add_dependency(hc, name)
```

## Arguments

- hc:

  A `highchart` `htmlwidget` object.

- name:

  The path to a packaged plugin, such as
  `"plugins/highcharts-regression.js"`

## Details

Use
[`highchart()`](https://jkunst.com/highcharter/reference/highchart.md)
for built-in modules and
[`highchartstock()`](https://jkunst.com/highcharter/reference/highchartstock.md)
for Stock Tools and technical indicators.
