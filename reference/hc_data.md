# Data options for highcharter objects

The Data module provides a simplified interface for adding data to a
chart from sources like CVS, HTML tables or grid views. See also the
tutorial article on the Data module.

## Usage

``` r
hc_data(hc, ...)
```

## Arguments

- hc:

  A `highchart` `htmlwidget` object.

- ...:

  Options defined in <https://api.highcharts.com/highcharts/data>.

## Details

It requires the `modules/data.js` file to be loaded.

Please note that the default way of adding data in Highcharts, without
the need of a module, is through the series.*type*.data option.

  hc_chart(type = "column") |>
  hc_data(csv = "Month,Orders\nJan,12\nFeb,18\nMar,15")
