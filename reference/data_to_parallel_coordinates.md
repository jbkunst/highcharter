# Prepare series for a parallel coordinates chart

Prepare series for a parallel coordinates chart

## Usage

``` r
data_to_parallel_coordinates(data, ...)
```

## Arguments

- data:

  A data frame of numeric measurements. Each row is an observation and
  each column is an axis, in display order.

- ...:

  Named series options such as `name` or `color`. Supply one value for
  all observations or one value per row.

## Value

A tibble for
[`hc_add_series_list()`](https://jkunst.com/highcharter/reference/hc_add_series_list.md)
with one series per row. Its `data` column holds the measurements in
their original units. Missing measurements leave gaps on their axes.

  hc_xAxis(categories = names(measurements)) |>
  hc_add_series_list(series)
