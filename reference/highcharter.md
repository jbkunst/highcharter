# An `htmlwidget` interface to the Highcharts javascript chart library

Highcharts <https://www.highcharts.com/> is a mature javascript charting
library. Highcharts provide a various type of charts, from scatters to
heatmaps or treemaps.

## Licensing

The R wrapper in `highcharter` is licensed under MIT. Every chart
created with `highcharter` uses the bundled Highcharts JavaScript
library. Your use of Highcharts must be covered by the applicable
Highsoft terms for [commercial use](https://shop.highcharts.com/license)
or [personal and educational
use](https://shop.highcharts.com/license-eula).
