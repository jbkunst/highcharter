# Pokémon types and base stats

A fixed collection of 898 Pokémon (IDs 1 to 898). Height is in
decimetres and weight is in hectograms. Includes types, stats, colors
and artwork links.

## Usage

``` r
pokemon
```

## Format

A data frame with 898 rows and 24 columns.

## Source

[PokéAPI](https://pokeapi.co/) and Bulbapedia.
