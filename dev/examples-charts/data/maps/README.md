# Website map snapshots

These unmodified GeoJSON maps come from the official
[Highcharts map collection](https://github.com/highcharts/map-collection-dist),
downloaded from its `master` branch on 2026-11-16. Local copies let the website
examples render without depending on the map CDN.

| File | Upstream path |
| --- | --- |
| `custom-world-robinson-lowres.geo.json` | `custom/world-robinson-lowres.geo.json` |
| `custom-world.geo.json` | `custom/world.geo.json` |
| `custom-europe.geo.json` | `custom/europe.geo.json` |
| `custom-south-america.geo.json` | `custom/south-america.geo.json` |
| `countries-nz-nz-all.geo.json` | `countries/nz/nz-all.geo.json` |

Retain the copyright and attribution metadata embedded in each file and keep
the map credits visible. Highcharts licensing also applies to its map collection.
Refresh these snapshots deliberately when reviewing an upstream map update.

`custom-world.topo.json` was downloaded unchanged from
<https://code.highcharts.com/mapdata/custom/world.topo.json> on 2026-11-16.
It contains geographic coordinates and is used by the homepage grid with
Highcharts' built-in Equal Earth projection and MapView zoom. Its embedded
copyright and attribution metadata are preserved.
